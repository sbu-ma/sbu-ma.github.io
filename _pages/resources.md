<div class="research-area" markdown="1">
### IPC: A New Benchmark Graph Dataset &nbsp;[[GitHub]](https://github.com/IBM/IPC-graph-data)
A dataset of 2,439 labeled graphs for evaluating machine learning on graphs, with predefined training, validation, and test splits. It was first used to study graph neural networks for AI planning.
Related papers: [Online Planner Selection with Graph Neural Networks and Adaptive Scheduling](https://arxiv.org/abs/1811.00210) (AAAI 2020); [IPC: A Benchmark Data Set for Learning with Graph-Structured Data](http://jie-chen-ibm.appspot.com/pub/ipc_graph_data.pdf) (ICML 2019 Workshop).
</div>

<div class="research-area" markdown="1">
### IGB: Illinois Graph Benchmark &nbsp;[[GitHub]](https://github.com/IllinoisGraphBenchmark/IGB-Datasets)
A large-scale graph benchmark (with UIUC) with over 162× more labeled data than previous public large graph datasets, for systematic evaluation of GNNs. Paper: [KDD 2023 ADS](https://openreview.net/forum?id=iVPVwyiL5F).
</div>

<div class="research-area" markdown="1">
### FastGCN (ICLR 2018) &nbsp;[[Paper]](https://arxiv.org/abs/1801.10247) [[Code]](https://github.com/matenure/FastGCN)
Speeds up training of graph convolutional networks via importance sampling, reducing computation substantially while keeping comparable prediction accuracy.
</div>

<div class="research-area" markdown="1">
### Drug Similarity Integration Through Attentive Multi-view Graph Auto-Encoders (IJCAI 2018) &nbsp;[[Paper]](https://arxiv.org/abs/1804.10850) [[Code]](https://github.com/matenure/mvGAE)
Learns interpretable drug similarity measures from multiple types of drug features, using attention to weight each view.
</div>

<div class="research-area" markdown="1">
### EvolveGCN — AML Transaction Graph Dataset &nbsp;[[Data]](https://github.com/IBM/AMLSim/tree/master/sample/%2020K%20cycle200.tgz)
Dynamic transaction graph used in [EvolveGCN](https://arxiv.org/abs/1902.10191) (AAAI 2020).
</div>
